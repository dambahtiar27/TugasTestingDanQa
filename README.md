## Deskripsi Proyek

Proyek ini bertujuan untuk melakukan pengujian perangkat lunak pada website bisnis menggunakan metode dan standar pengujian yang relevan.

## Tujuan
1. Mengidentifikasi kualitas aplikasi.
2. Melakukan pengujian perangkat lunak.
3. Mengidentifikasi dan mendokumentasikan bug.
4. Melakukan evaluasi berdasarkan standar IEEE dan ISO.
